Quick Start

Build from source:

git clone https://github.com/Cass67/forge
cd forge
just build

Start using:

# Configure your LLM provider
forge config set claude

# Terminal chat
forge chat "add a feature to read JSON files"

# Desktop GUI
forge gui

Resume a session:

forge --continue # resume most recent session
forge --resume <id> # resume specific session
